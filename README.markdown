## `> KEY FEATURES_`

<table>
<tr>
<td width="50%" valign="top">

### Steganography
![Steganography](https://img.shields.io/badge/Steganography-LSB%20Embedding-00FF41?style=for-the-badge&logo=image&logoColor=white)

Hide your encrypted messages inside ordinary PNG images. Uses Least Significant Bit (LSB) embedding — the image looks identical to the naked eye, but contains your secret data.

```
Original Image + Secret Message
        ↓ LSB Embed
  Stego Image (looks identical)
        ↓ LSB Extract
    Secret Message Recovered
```

---

### NFC/QR Key Sharing
![NFC](https://img.shields.io/badge/NFC-Tap%20to%20Share-58a6ff?style=for-the-badge&logo=nfc&logoColor=white)
![QR](https://img.shields.io/badge/QR-Scan%20to%20Share-58a6ff?style=for-the-badge&logo=qrcode&logoColor=white)

Share encryption keys securely without typing. Tap phones together (NFC) or scan a QR code. The key never touches the internet.

</td>
<td width="50%" valign="top">

### Biometric Key Storage
![Biometric](https://img.shields.io/badge/Biometric-Hardware%20Backed-ff6b6b?style=for-the-badge&logo=fingerprint&logoColor=white)

Encryption keys are stored in the Android Keystore, protected by your fingerprint or face. Keys never leave the secure hardware enclave. Even root access cannot extract them.

```
Biometric Auth → Android Keystore
    → Hardware Security Module
        → Key Released to Memory
            → Key Zeroed After Use
```

---

### Fake Terminal Mode
![Terminal](https://img.shields.io/badge/Fake%20Terminal-Decoy%20Mode-gold?style=for-the-badge&logo=windowsterminal&logoColor=white)

Activate the decoy terminal that simulates a realistic hacker shell. If someone forces you to open the app, switch to this mode — it shows fake commands and outputs, hiding all real functionality behind a convincing facade.

```
$ sudo nmap -sS 192.168.1.0/24
[*] Scanning 256 hosts...
[+] 12 hosts discovered
$ _
```

</td>
</tr>
</table>

## `> DEBUGGING & TROUBLESHOOTING_`

<details>
<summary><b>Common Issues</b></summary>
<br/>

| Issue | Cause | Solution |
|:------|:------|:---------|
| Biometric prompt not showing | No biometric enrolled | Enroll fingerprint/face in device settings |
| NFC sharing fails | NFC disabled or unsupported | Enable NFC in quick settings; check device compatibility |
| Decryption fails | Wrong password or algorithm | Ensure same algorithm and exact password used for encryption |
| Large file hangs | Insufficient RAM | Close other apps; use streaming mode for files >100 MB |
| `.leecrypt` file not recognized | File association missing | Open file with LeeCrypt via "Open with" menu |
| Stego image too small | Payload exceeds image capacity | Use a larger image or compress your message first |
| BLAKE3 crash on x86 emulator | JNI binary incompatibility | Test on ARM device or ARM emulator image |

</details>

### Steganografie
![Steganografie](https://img.shields.io/badge/Steganografie-LSB%20Embedding-00FF41?style=for-the-badge&logo=image&logoColor=white)

Verberg je versleutelde berichten in gewone PNG-afbeeldingen. Gebruikt Least Significant Bit (LSB) embedding — de afbeelding ziet er identiek uit voor het blote oog, maar bevat je geheime data.

```
Originele Afbeelding + Geheim Bericht
        ↓ LSB Embed
  Stego Afbeelding (ziet er identiek uit)
        ↓ LSB Extract
    Geheim Bericht Hersteld
```

### Biometrische Sleutelopslag
![Biometrie](https://img.shields.io/badge/Biometrie-Hardware%20Backed-ff6b6b?style=for-the-badge&logo=fingerprint&logoColor=white)

Encryptiesleutels worden opgeslagen in de Android Keystore, beschermd door je vingerafdruk of gezicht. Sleutels verlaten nooit de beveiligde hardware-enclave. Zelfs root-toegang kan ze niet extraheren.

```
Biometrische Auth → Android Keystore
    → Hardware Security Module
        → Sleutel Vrijgegeven aan Geheugen
            → Sleutel Gewist Na Gebruik
```

## `> PROBLEEMOPLOSSING_`

<details>
<summary><b>Veelvoorkomende Problemen</b></summary>
<br/>

| Probleem | Oorzaak | Oplossing |
|:---------|:--------|:----------|
| Biometrische prompt verschijnt niet | Geen biometrie ingesteld | Stel vingerafdruk/gezicht in via apparaatinstellingen |
| NFC-deling mislukt | NFC uitgeschakeld of niet ondersteund | Schakel NFC in via snelle instellingen; controleer apparaatcompatibiliteit |
| Ontsleuteling mislukt | Verkeerd wachtwoord of algoritme | Zorg dat hetzelfde algoritme en exact wachtwoord wordt gebruikt |
| Groot bestand hangt | Onvoldoende RAM | Sluit andere apps; gebruik streamingmodus voor bestanden >100 MB |
| `.leecrypt` bestand niet herkend | Bestandsassociatie ontbreekt | Open bestand met LeeCrypt via "Openen met" menu |
| Stego-afbeelding te klein | Payload overschrijdt afbeeldingscapaciteit | Gebruik een grotere afbeelding of comprimeer je bericht eerst |
| BLAKE3 crash op x86 emulator | JNI binary incompatibiliteit | Test op ARM-apparaat of ARM-emulatorimage |

</details>
